# 공강 2D — 함께 바라보는 세상

같은 공간에서 실제 접속한 여행자들과 함께 아름다운 풍경을 감상하는 2D 온라인 쉼터

## 현재 공간
- **별빛 전망대** (`/?map=stargaze`): 고밀도 성운 먼지·별빛, 다층 산맥·안개, 달빛 풀밭·야생화와 자연 유성, 8인 동행
- **한강의 밤** (`/?map=river`): 기존 강변 산책과 야경

## 상호작용
- 이동(모바일 조이스틱·PC 방향키/WASD), 서기·앉기·눕기·인사·빛
- **전체 풍경 ↔ 나만의 시점**: 별빛 전망대에서는 멀리서 사람들과 함께 바라보거나 2D 하늘 몰입 구도로 전환
- **함께 보는 유성우/불꽃놀이**: 별빛 전망대의 실제 접속자들이 서버에서 전달한 동일한 시작 시간·시드로 감상. 90초 재실행 제한
- 사진 촬영: 기존 미리보기·PNG 저장·모바일 촬영 모드 유지
- 이름이나 계정 없는 최대 8인 동행. 허위 온라인 인원이나 가상 방문자 표시 금지

## 기술
- Node.js WebSocket 서버(`/presence`), Canvas 2D 절차적 자연 렌더링
- Railway 웹 앱과 Supabase `gongang2d_visits` (익명 방문 통계) 구조 유지
- 입장한 실제 사용자만 렌더링, 좌표·행동 서버 검증, 방별 이벤트 동기화
- `npm install && npm start`: 로컬 실행
- `npm run check`: 코드 구문 검사·실제 8개 연결의 자세/이벤트 동기화·9번째 입장 제한 테스트
- GitHub Actions: 실제 브라우저에서 데스크톱/모바일/나만의 시점/불꽃놀이/사진 촬영 검사

## 2026-11-10: 회화풍 별빛 전망대
- 사용자가 선택한 **인물 없는 원본 풍경**을 자체 WebP 아트로 저장하고 별빛 전망대의 주 배경으로 사용
- 총 6개 이미지 자산: 기본 원화(약 352 KiB), 모바일 전용(약 117 KiB), 산 깊이·전경 풀밭·두 겹 안개(합계 약 201 KiB)
- 주 이미지 위에 가장자리/거리에 따른 작은 시차와 미세한 안개 이동, 소수의 별 반짝임만 실시간 표시
- **Canvas 배경 절차 생성 및 9겹 정적 캐시 메모리 사용을 생략**해 모바일 메모리 및 최초 화면 처리 부담 감소
- 8인 익명 동행·앉기·눕기·개인 시점·사진 촬영·유성우·불꽃놀이·기존 한강 맵 기능은 그대로 보존
- 이미지 파일을 열지 못한 경우 이전 Canvas 풍경을 예비 화면으로 사용

## 디자인 방향
자연이 주인공인 광활한 풍경, 작은 캐릭터들의 조용한 동행, 은은한 입자와 빛, 드문 자연현상과 특별 이벤트를 중심으로 제작. 복잡한 게임·채팅보다 감상과 힐링에 집중한다.

별빛 전망대는 비대칭 산 능선과 골짜기 명암, 밀도에 따른 구름의 은빛 윗면과 그늘,
청보라에서 따뜻한 장밋빛으로 이어지는 은하수를 9겹의 경량 Canvas 레이어로 캐시한다.
먼 산과 중간 산 사이·중간 산과 가까운 산 사이의 계곡 안개는 각각 1/2 해상도에 미리 그리고
천천히 이동시킨다. 달빛 풀밭에 자연스러운 쉼터와 가장자리 풀 실루엣도 추가했다.
레이어는 정적 6장과 1/2 해상도 3장으로 전체 캔버스 캐시 메모리를 약 53MiB로 제한한다.
Stellar Explosion v31.9 / Quasar v129의 128px 입자 알파 프로필은 유지하며,
은하수와 별이 같은 먼지 분포를 사용한다. 반짝임은 최대 155개로 제한하고
산 뒤나 구름에 가려진 별의 반짝임은 감쇠한다. 배경은 시점 변경·촬영 시 다시 생성하지 않는다.

> 2026년 11월부터 상명대 단풍길은 공강 2D에서 제외했다. 예전 `/?map=campus` 링크는 별빛 전망대로 자동 전환되며, 기존 `gongang` 3D 프로젝트에는 영향이 없다. 공연·별빛 이벤트는 실제 접속자끼리만 공유된다.
